## 1. Overall Experience & Navigation

### Core Interaction Model

When visitors land, they see a mesmerizing 3D canvas filled with **floating abstract particle clusters** (organic, blob-like forms with internal particle systems - like cells under a microscope with cyberpunk glow effects). These clusters slowly drift, rotate, and pulse. Background is deep dark blue-black (#050816) with subtle grid pattern.

### Navigation System: 5 Main Particle Clusters

Pentagon formation in 3D space:
1. **Center cluster (Home/Hero)** - Largest, most complex
2. **About/Skills cluster** - Top-right
3. **Experience cluster** - Right
4. **Projects cluster** - Bottom
5. **Contact cluster** - Left

### How It Works

**Initial state:** All clusters are abstract, beautiful, glowing blobs with particle systems inside

**Hover:** Cluster glows brighter, particles speed up, cursor changes to "explore"

**Click:** Camera smoothly transitions to that cluster (zooms in and centers it), the blob **morphs/unfolds** into a structured diagram revealing the technical content with labels, connections, and data

**Navigation between sections:** Click another cluster OR use traditional nav menu (glassmorphic bar at top) OR scroll (which auto-transitions clusters)

**The Magic:** It looks like art, but every cluster is actually a diagram of your expertise waiting to be discovered.

### Performance Optimizations

**1. Instanced Rendering:**
- Use `InstancedMesh` for particles (render 10,000+ particles in 1 draw call)
- Shared geometry and materials across instances

**2. Level of Detail (LOD):**
- Reduce particle count on mobile (5000 → 2000 particles)
- Simplify shaders on low-end devices

**3. Lazy Loading:**
- Code-split each cluster component
- Load 3D models/textures on demand using `Suspense`

**4. Frame Rate Management:**
- Use `useFrame` hook with delta time for consistent animation
- Throttle expensive calculations (morph animations) to 60fps max

**5. GPU Optimization:**
- Use BufferGeometry for efficient vertex data
- Minimize state changes in render loop
- Use shader-based animations where possible

**6. Bundle Size:**
- Tree-shake unused Three.js modules
- Compress textures (use WebP format)
- Lazy load EmailJS only on Contact section

1. **Hybrid Technical/Abstract:** Beautiful at first glance, technically deep on interaction
