STACK 2026

My opinionated read of the 2026 agentic-AI ecosystem. I cross-checked it across four parallel research agents and against Google Gemini's seven-layer framing, then mapped the whole thing onto what I'm already running on Athena: LangGraph.js, Neo4j, MCP, K3s. This is where I'm placing my bets.

MCP won.
~9.4K servers in the wild. Anthropic donated it to the Linux Foundation's new Agentic AI Foundation in Dec 2025 alongside OpenAI, Google, AWS & Microsoft.
02 / TS ORCHESTRATION
Mastra > LangGraph.js for new work.
22K stars in 15 months, 300K weekly npm downloads, Replit / SoftBank / PayPal in prod. I'm keeping LangGraph.js for my existing graph-heavy work in life-optimization.
03 / MY EDGE

Evals + HITL, not more frameworks.
Quality is the #1 production blocker (32% of teams). EU AI Act Article 14 enforceable Aug 2, 2026 — HITL is no longer optional.

L02

Memory & Cognition

The operating system. Solves "the goldfish problem" — stateless LLMs can't accumulate context across sessions. True agent memory is stateful, mutable, time-aware, scoped per project.

Neo4j + pgvector hybrid
GRAPHRAG · I RUN THIS
Vector recall + Cypher multi-hop. Microsoft GraphRAG benchmarks: +26% comprehensiveness, +57% diversity over flat vector. Already running it in life-optimization.
Athena infrastructure · already in life-optimization
Mem0
SENSIBLE DEFAULT
Auto-extracts facts to vector + graph + KV. Handles deduplication and write-time contradictions. ~90% token-reduction vs naive baselines; 26% LoCoMo improvement.
Drop-in for chatbot-style memory
Letta (MemGPT)
DAY-SCALE AGENTS
OS-inspired tiered memory; agent pages memory in/out via tools. The only choice for agents running autonomously for days. Reliability gap if the model fails to call the save tool.
Composable with LangGraph / Mastra
Zep (Graphiti)
TEMPORAL KG
Every fact has valid_from/valid_to. Handles entity mutations cleanly ("used to live in London, now Tokyo"). Best when state evolves.
Needs Neo4j / FalkorDB under it
Qdrant (when I outgrow Chroma)
VECTOR DB · NEXT-TIER
Rust, single binary, best filter expressiveness for per-user namespacing. Drops into K3s cleanly via Helm.
Sticking with Chroma until I outgrow it
Anthropic Filesystem Memory
TRANSPARENT · DIY
Exposes memory as /memories. Max control, min opinion — I'd have to build the semantic extraction layer myself. Powerful for Claude-Code-style agents.
Only if I want to engineer it
Gemini's outlier picks: "Evermind / EverOS" (claimed 83% LongMemEval-S, 93% LoCoMo) and "MinnsDB" (49 native connectors) are real products but didn't show up in cross-checks — treat as watch list, not bet list, until adoption signal is clearer.
L03

Protocols & Interoperability

Solves the NxM problem — N models × M tools = a combinatorial mess of bespoke integrations. Standards eliminate the friction.

MCP — Model Context Protocol
TOOL LAYER · I SHIP THIS
JSON-RPC 2.0 over STDIO / SSE / Streamable HTTP. Anthropic-originated; donated to Linux Foundation AAIF Dec 2025. ~9.4K servers; Stripe, Linear, Atlassian, Salesforce, GitHub ship first-party. 2026-07-28 RC drops session state & sticky routing — design stateless now.
Already shipped in my time-boxing app
A2A — Agent2Agent
AGENT-TO-AGENT · LEARN NEXT
Google-originated, donated to LF June 2025; v1.0 with Signed Agent Cards. 150+ orgs, native in Azure AI Foundry, Bedrock AgentCore, Google Cloud. Different lane from MCP — orchestration, not tools. Q3 2026 MCP/A2A joint spec in flight.
Build an A2A endpoint after MCP is solid
AG-UI
AGENT ↔ USER UI
CopilotKit-driven. Agents render rich widgets / forms / charts back into my React app instead of dumping text into a chat. The natural next step for my time-boxing dashboard.
Pairs naturally with Mastra
OAuth 2.1 + PRM + CIMD
AUTH FOR MCP SERVERS
Dynamic Client Registration is out; Protected Resource Metadata (RFC 9728) and Client ID Metadata Documents are now the recommended path. Cloudflare's enterprise-MCP architecture is the reference.
Required for anything multi-tenant
AGNTCY (Cisco-led)
WATCH · DON'T SHIP
Agent identity, directory, ACP messaging, OASF schema. Real code, real members, thin adoption. Useful for identity standards when they harden.
Not actionable today
IBM ACP (yes, different ACP)
IGNORE UNLESS IBM ORBIT
Two specs named ACP both live under the LF umbrella. IBM's powers BeeAI. Not relevant outside that ecosystem.
Not for my stack
My next move: I'm already an MCP shipper. The single highest-leverage protocol play left for me in 2026 is to add an A2A endpoint with a signed Agent Card — that gets me Azure / Bedrock / Google interop for free.
L04

Orchestration Frameworks

Defines how agents reason — graph? crew? swarm? handoffs? The single highest-impact architectural decision after model choice.

Mastra (TypeScript)
NEW WORK · DEFAULT
YC W25, $13M seed, 22K stars in 15 months, 300K weekly npm. Deploys on Vercel / Cloudflare (LangGraph Platform can't). Built-in memory, workflows, evals. Sits on Vercel AI SDK.
Caveat: multi-agent is rated "⚠️" vs LangGraph "✅"
LangGraph.js
KEEP · MY EXISTING WORK
Explicit StateGraph; deepest control + best HITL story. 42K weekly npm downloads; Replit / Uber / LinkedIn / JPMorgan in prod. Stay here for life-optimization — don't rewrite.
Verbose. Recent CVE in SQLite checkpointer (March 2026)
OpenAI Agents SDK
OPENAI-CENTRIC
Evolved from Swarm; handoffs as tool calls. Temporal integration GA March 2026 for durable execution. Sandboxing + guardrails built-in.
26K stars; less "graph" thinking than LangGraph
Anthropic Claude Agent SDK
⚠ BILLING SHIFT JUNE 2026
Same agent loop that powers Claude Code. Heads-up: June 15 2026 billing splits SDK into a separate credit pool — community analyses show 12-175× effective price increases for continuous workloads on subscription plans.
Fine for occasional automation; expensive always-on
CrewAI
FASTEST PROTOTYPE · WORST PROD
47K stars, role-based crews. Benchmarks show ~3× tokens / 3× latency vs LangChain on basic tasks; "doubting loops" retrigger searches up to 35× per run. Teams migrate off at scale.
Demos > production
Pydantic AI
PYTHON · TYPE-SAFE
17K stars; v1.x stable. Best type-safety in Python. Pair with Logfire to shift errors from runtime to write-time. Boring is good.
Python-only — not my stack
Agno (formerly Phidata)
PYTHON · BATTERIES INCLUDED
Bundles AgentOS — control-plane UI, session mgmt, local-DB memory. Easiest path for Python teams that don't want graph plumbing.
Python-only
Microsoft Agent Framework
.NET / AZURE
1.0 GA April 3 2026 — merged AutoGen + Semantic Kernel into one framework. Wrong ecosystem for me.
Skip
Temporal / DBOS / Inngest
DURABILITY LAYER (not a framework)
Long-running agents need replay + checkpoint + HITL pauses. DBOS is a library on Postgres (no extra cluster) — perfect for my already-Postgres setup. Temporal is for enterprise-scale, which I'm not.
Add when a run can take >5 min
L05

Tools, RAG & Sandboxes

Where agents touch the world. Highest-moat layer — frameworks commoditize, proprietary tools + curated data stay defensible.

Hybrid + Graph + Agentic RAG
RETRIEVAL STACK
Hybrid: dense + sparse (SPLADE/BM25) for keyword + semantic. Graph: walk a KG superimposed on the corpus. Agentic: the LLM picks the source, writes the query, verifies the answer. I'm using all three — already have the KG.
Hybrid + Graph + Agentic = current ceiling
Modal (sandbox · GPU-capable)
CODE EXECUTION
gVisor isolation; only sandbox provider whose sandbox can hold a GPU. Pick if the agent runs inference inside the sandbox.
Officially integrated with OpenAI Agents SDK
E2B (sandbox · Firecracker)
SAFEST DEFAULT
Hardware-level microVM isolation. The safe default for running untrusted LLM-generated code. I'm not running untrusted code inside my own K3s — Athena is too valuable to be a sandbox host.
~Sub-second cold starts
Daytona
PERSISTENT ENVS
Docker-based, sub-90ms cold starts (27ms tuned), persistent envs across sessions. Best when the agent comes back to the same workspace.
For dev-environment-style agents
Steel.dev (self-hosted browser)
ATHENA-NATIVE
Apache 2.0, Docker one-liner, anti-detection plugins. I'll drop it into K3s as a Deployment. My pick for browser tools on Athena.
Stagehand if I move to SaaS
Browserbase + Stagehand v3
MANAGED BROWSER
"AWS for headless browsers." Stagehand v3 (Feb 2026, 44% faster) is the TS-native control plane. Use when self-hosted Steel can't keep up.
$40M Series B at $300M val
vLLM + KubeAI (self-hosted inference)
ATHENA · LOCAL MODELS
vLLM is the default; KubeAI is the K8s operator (handles model pulls, caching, cold-start buffering). I'll reach for SGLang if my workload turns out RAG-heavy — RadixAttention gives ~6× throughput on prefix-cached prompts.
Cost lever for routing-tier work
LiteLLM (pinned) or Portkey OSS
MODEL GATEWAY
In-cluster Service routing easy steps → local vLLM, hard steps → Claude/GPT. Pin LiteLLM — March 2026 supply-chain attack on v1.82.7–8.
Portkey if I want stronger governance OOTB
Anthropic MCP tunnels
PRIVATE TOOL EXPOSURE
Expose internal MCP servers to Claude Managed Agents without public internet exposure. Could've been designed for my exact K3s setup.
Shipped May 2026
L06

Application / Agent UI

The terminal interface. Chatbots are commodity; generative UI is the frontier. Coding-agent UX has matured fastest — the rest is catching up.

CopilotKit + AG-UI
GENERATIVE UI · TS-NATIVE
Agent renders live React widgets / forms / charts into my app. Pairs naturally with my time-boxing dashboard and any Mastra workflows I add.
Real upgrade over chat-only UX
Vercel AI SDK v6
STREAMING + AGENT ABSTRACTION
v6 added a real Agent abstraction with stopWhen, tool-approval, MCP, DevTools. Best for chat-UI-first apps. Mastra sits on top of this.
Already part of the TS surface area
Claude Code / Cursor / Windsurf
CODING AGENT SURFACES
The most mature application of agentic AI. Cursor/Windsurf in IDE, Claude Code in terminal. Use them — don't build them.
Compounding compounders
AIMock-style proxies
AGENT TEST INFRA
Single-config proxy for 11+ LLM providers; supports drift detection, schema validation, chaos injection (500s, mid-stream disconnects). Critical for non-deterministic systems.
Real category, multiple competitors
Moat note: horizontal chat UIs are crowded and easily replicated. Vertical SaaS embedding agentic workflow into a niche industry is what compounds — 28% YoY growth, 3–5× retention vs horizontal competitors.
L07

Observability, Evals & Security

The control plane. As my agents start touching databases, code, and money, output guardrails won't be enough — I need execution traces, eval gates, and threat-aware policy.

Langfuse (self-hosted)
ATHENA · OBSERVABILITY
MIT-licensed; runs on Postgres + ClickHouse (Postgres I already have). OTLP ingest. Acquired by ClickHouse Jan 2026, still OSS. The clear self-host winner over LangSmith for my setup.
Helm chart available
LangSmith
SAAS · DEEPEST LANGGRAPH INTEGRATION
Node-by-node state diffs, replay against new model versions. The pay option if I stay on LangGraph and want zero ops.
$39/seat + $0.50/1k traces
DeepEval
EVALS · CI GATING
50+ metrics including agent-specific (task completion, tool correctness, step efficiency). Pytest-flavoured.
First eval lib to learn
Promptfoo
EVALS · RED-TEAMING
Node.js-native. Acquired by OpenAI March 2026, MIT core stays.
Pair with DeepEval
OWASP Agentic AI Threats
SECURITY FRAMEWORK
15 scenarios unique to autonomous systems. Watch especially T6 Intent Breaking (Shadow Escape exploit hit Gemini/ChatGPT), ASCII smuggling, T2 AI-in-the-Middle phishing, T5 Cascading Hallucinations.
Audit against this before going public
HITL (human-in-the-loop)
REGULATORY · MANDATORY
EU AI Act Article 14 enforceable Aug 2, 2026; California SB-833 July 1. HITL document extraction hits 99.9% vs 92% AI-only. Use LangGraph interrupt() at every Neo4j write and external tool call.
No longer optional
OPA + Lakera + BigID
POLICY · INLINE SAFETY · PRIVACY
Open Policy Agent for granular permission, Lakera for inline action evaluation, BigID for data-privacy enforcement. Layered defense.
Enterprise — overkill for solo
This is the gap I'm closing first. Quality is the #1 production blocker industry-wide (32% of teams), and every senior agent-engineer JD lists evals + tracing. Closing this single gap is what converts my hobby agents into a portfolio piece.

My 12-Month Path

Building on what I already have. Closing the highest-leverage gap first (evals + observability), then layering on multi-agent + HITL, then self-hosted inference, then making konfigura compound, and finally shipping one vertical end-to-end.

MONTHS 1 – 2 · HIGHEST LEVERAGE
Wire Langfuse + a 30-case eval suite into life-optimization
Deploy Langfuse self-hosted on Athena (Helm chart, pointed at my existing Postgres). Add OpenTelemetry instrumentation to the LangGraph.js agent. Build a 30+ trajectory eval suite with DeepEval + an LLM-as-judge rubric. This single move turns my hobby agent into a portfolio piece.
MONTHS 2 – 4 · MULTI-AGENT + HITL
Refactor life-optimization into orchestrator-worker with interrupt() gates
Splitting it into planner → Neo4j-write worker → retrieval worker → evaluator-optimizer pass. Adding LangGraph interrupt() approval at every Neo4j write and external tool call. EU AI Act Article 14 enforcement starts Aug 2, 2026 — HITL isn't optional anymore.
MONTHS 4 – 6 · LOCAL INFERENCE
vLLM + KubeAI on Athena serving Qwen3 235B-A22B
Routing via LiteLLM in-cluster — local model for classification + routing, Claude/GPT for the hard reasoning. I'm writing up the cost/latency comparison as a public artifact; that writeup alone is something I can put in front of a hiring manager.
MONTHS 6 – 9 · DSL COMPOUNDING
Reframing konfigura as a compiler-in-the-loop agent
"AI-generated DSL + compiler-feedback agent loop" — taking sub-20% baseline accuracy to ~85%. Go for the compiler, TS (Mastra) for the agent loop. Two birds, one project. The publishable angle is the feedback-loop architecture.
MONTHS 9 – 12 · SHIP ONE VERTICAL
Ship one outcome-priced vertical agent, end-to-end
Picking one surface — journaling-as-coaching, productivity analytics, or infra automation — and shipping the whole loop: agent + memory + tools + HITL + evals. This is the artifact that converts everything else into a job offer or a seed round. Sequoia/a16z's 2026 thesis is vertical + narrow + outcome-priced wins, and I agree with them.
